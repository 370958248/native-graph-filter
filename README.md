# 全局关系过滤

让思源自带的全局关系图只展示你想看的范围。

![虚构示例](preview.png)

预览全部使用虚构笔记，不含真实用户资料。当前界面为简体中文。

## 功能

- 隐藏整个笔记本，或指定文档及其下级，相关节点和连线一并排除。
- 保留原生关系图的绘制、缩放、点击、搜索与全屏交互。
- 设置窗口中的目录默认收起，仅展开时读取对应层级。
- 支持暂停、移除单项或清空隐藏范围，取消窗口会放弃未保存的调整。
- 设置保存检查思源返回的成功状态；保存异常、错误码和超时不会直接改变当前显示范围。
- 停用插件后恢复原生显示；局部关系图不参与过滤。

## 开始使用

1. 安装并启用“全局关系过滤”。首次使用默认不隐藏任何内容。
2. 打开思源自带的“全局关系图”。
3. 点击顶部或全局关系图中的漏斗图标，勾选需要隐藏的笔记本；也可以展开目录，勾选某篇文档及其下级。
4. 点击“应用”。取消“启用过滤”后应用，可以暂时恢复完整的原生结果。

原文、真实双链和笔记索引保持原样。隐藏只影响图面显示，不是加密或访问权限控制。以前安装过本地试用版的用户，已有隐藏范围会继续使用。

## 原生节点上限

**本插件只过滤原生接口已加载的节点，不会补载原生上限之外的内容，也不会提高原生节点上限。**

例如，原生加载了16384个节点，其中15000个属于被隐藏的资料，过滤后可能只剩1384个。这不代表你的其他笔记只有1384个。设置窗口会显示当前加载、将隐藏及将显示的节点数。

## 兼容性

- 最低思源版本声明为3.8.9，已在Windows思源3.8.9桌面端和桌面浏览器中验证。macOS/Linux尚未实机验证，未声明移动端或独立设置窗口支持。
- 通过思源内部的全局关系图绘制入口提供过滤。当前没有官方专用过滤扩展接口，思源升级后可能需要适配。
- 如果其他插件也修改同一绘制入口，可能存在兼容问题；停用时只恢复自己仍持有的方法，不强行覆盖后续第三方包装器。
- 选择器只列出已打开的普通笔记本，暂不支持加密笔记本。
- 文档移动后，若新的原生结果包含该文档根节点，会按当前位置匹配；否则需要重新选择该文档。整笔记本的隐藏不受文档移动影响。

## 数据与隐私

选择器只读取笔记本列表和按需展开的目录元数据，不额外请求笔记正文。过滤仅检查原生节点已有的所属范围，不改变网络层或原生查询配置，不调用外部服务。

设置通过官方插件接口保存在插件自己的 `filters.json` 中，不属于安装包。通用安装包不预设任何用户笔记本，也不包含笔记、个人隐藏规则或登录凭据。插件不在思源网页发布服务中启用。

## 手动安装

下载仓库Release中的 `package.zip`，解压至工作空间的 `data/plugins/native-graph-filter/`，确认 `plugin.json` 和 `index.js` 直接位于该目录，再在思源中启用插件。

## 开发与打包

原生JavaScript，无第三方运行时依赖。需要Node.js运行测试，Python 3执行打包。

```sh
node --test tests/filter.test.cjs
python build.py
```

打包脚本从 `main.js`、`filter.js`、`bridge.js` 和 `ui.js` 生成单入口 `index.js`，输出根目录下的 `package.zip`，并检查清单、图片与通用文件中可能泄露的笔记编号或本机路径。
